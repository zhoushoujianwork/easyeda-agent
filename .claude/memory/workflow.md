# 布局算法验证交付

- 每轮代码编辑并完成相关验证后做一次本地 git commit，交付 commit hash 供用户查看 diff；只提交本轮相关文件，不夹带用户其他改动。该约定不自动要求 push 或发布版本。

- 算法讨论与迭代使用固定 CLI `sch layout-render` 从布局数据编译图片，不临时让 AI 编写绘图脚本。当前用户要求只展示布局图，暂不自动打印差异图解；需要比较时再按用户要求启用。
- 图解必须区分合成测试、已有数据离线预览、EDA 实际导图；离线预览通过不等于现场通过。预览与 Apply 应消费同一份已校验的目标几何，Apply 后再回读并用官方导图对照。

- 每次完成布局算法的现场验证，保留修改前和修改后的官方图像供核验；展示时遵循当前不自动打印差异图解的要求，标明是否为实际落图或离线预案。
- 同时报告连通性、重叠、面积/线长等本次实际验证项；失败或中止时保留前图并明确没有通过验收，不伪造后图。
- 原始题图和包含练习电路的对比图保存在本地忽略目录，不提交公共仓库。
