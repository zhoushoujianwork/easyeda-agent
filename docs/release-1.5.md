# 1.5 发布与验证

本次发布 **v1.5.0**，把此前本地开发验证的布局、数据复用和运行时修复合入正式版本。
版本与下载以 [GitHub Release](https://github.com/zhoushoujianwork/easyeda-agent/releases/tag/v1.5.0)
为准，完整条目见 [Changelog](../extension/CHANGELOG.md)。

## 升级边界

- CLI/daemon、Skill、DSH bundle 和连接器发布资产统一为 1.5.0，连接器 UUID 不变。
- 连接器增加了有界身份读取/请求内缓存，以及脚本编译拒绝与运行失败的区分。
  因此按仓库兼容线规则升 minor，不能将本次作为无需更新连接器的 1.4.x patch 发布。
- `easyeda update` 更新 CLI 与 Skill；侧载连接器需从本次 Release 下载，卸载旧项后
  导入，并保存工程、重开 EDA 以加载新代码。升级/替换运行时后，在新的 Agent 会话中重新
  执行版本门禁。发布本身不会自动替换正在运行的本地开发环境。

## 功能范围

布局计算不再依赖先注册 Lib：普通组件集合可交 `sch layout-plan`，固定
`sch layout-render` 编译为 SVG。Zone 内的修复只影响自身，Zone 间按固定内边距和
Z 顺序放置；可计算有界的朝向、压缩与同页组合候选。通过审批的页布局可直接编译为
受保护 Apply 队列，不会在编译时悄悄重新排版。候选计算与实际 Apply/回读仍是不同阶段。

公共模块目录按就绪程度区分草稿、拓扑和可组合布局。打包只包含 Git 受控的公共 Skill
文件；题目正文、参考图、私有 UUID、临时验证产物及未跟踪草稿不随发行包发布。

离线开发包通过完整资产校验和 Skill 内容对账安装/检查；本地开发模式要求各运行时精确
同开发版，不是只改版本标记，也不跳过正式版会话门禁。

## 验证与已知限制

发布前执行 Go 与连接器测试、Skill/lint/module 审计、发行脚本测试，随后等待最终 main
提交的 Linux/macOS/Windows CI。发行资产包含五平台 CLI、连接器、Skill、安装器和
SHA-256 清单；发布后重新下载核对远端文件及本机 CLI 冒烟结果。

本次没有重跑 `esp32MiniRequire.md` 第一节到四层 PCB 的完整现场验收，不能把离线测试
和局部原理图验证等同于整板通过。EasyEDA 3.2.186 的一次现场会话中，原理图导图 API
对新旧符号均返回空文件；根因仍未确定，本版不宣称修复该接口。按键符号工作只留下私有
草稿，正式器件替换未完成，且没有为该次按键编辑改动 CLI 或连接器实现。
