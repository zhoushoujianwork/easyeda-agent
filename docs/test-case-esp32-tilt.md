# 示例与回归用例 — ESP32-S3 USB-C 体感小板

2026-11-26 用户确认新增本用例。它同时承担三件事：新用户第一次接触的示例工程、
EdaDesk 演示与审图入口的素材、以及介于[最小点灯板](test-case-esp32-blink.md)和
[四层扩展板](../esp32MiniRequire.md)之间的中档回归。当前状态：**planned / not-run**。

一句话效果：一根 USB-C 线插电脑即可供电和烧录；倾斜板子，LED 随姿态亮灭或闪烁。

执行 Agent **只接收第一节客户原始需求**；不提供 BOM、UUID、网表或坐标答案。
块映射、埋雷清单、演示回放与证据要求见[详细稿](test-case-esp32-tilt-detail.md)。

## 一、客户原始需求

做一块基于 ESP32-S3-WROOM-1 模组的 USB-C 体感小板：

- 一个 USB-C 口同时负责供电和烧录/串口，正反插都能用，不另加 USB 转串口芯片。
- USB 的 5V 降到 3.3V 给主控和传感器供电。
- 板载 BOOT 和 RESET 两个按键，保留正常启动、复位所需电路和电源去耦。
- 一颗 6 轴姿态传感器（加速度 + 陀螺仪），经 I²C 接到主控。
- 一颗电源指示灯和一颗 GPIO 控制的用户灯，带限流电阻，丝印标清正负极。
- 预留一个 1×4 排针：3V3、GND、TX、RX，方便外接调试。
- 一页原理图、两层 PCB，板子尽量小巧；模组天线伸出或贴近板边，并保留天线禁铜区。
- 完成原理图、PCB 布局和布线，位号可读、接口与极性丝印清楚，保存工程。

## 二、同一工程的三种形态

| 形态 | 给谁用 | 内容 |
|---|---|---|
| 原始需求 | 端到端回归 | 上面第一节；Agent 自行选型、读真实引脚、完成设计 |
| 完成版 | 新用户、EdaDesk 演示 | 一次通过验收的设计，导出 playbook；演示时在固定演示工程清页后用 `easyeda apply` 回放，真实写入并回读 |
| 埋雷版 | 审图演示、模型评测 | 在完成版上植入 6～8 个已知缺陷，每个缺陷有标准答案，也作为审查规则的负对照 |

演示不实时调用模型：回放快、成本近零、结果确定。演示过程显示真实回读和检查结果，不做假动画。

## 三、与现有用例的关系

- **最小点灯板**：保留，继续做日常快速收尾。
- **本用例**：改动影响 USB、I²C、多块组合、审查规则或演示流程时运行；作为新用户示例。
- **四层扩展板**：不变，仅在明确要求时运行。

本期不加屏幕、电池、降压芯片和音频；小屏（`st7789_spi_lcd_btb`）留作第二版升级。

## 四、实施顺序

1. 按第一节跑一次端到端，得到通过验收的完成版，并把各块的 PCB 状态回填到块库。
2. 导出完成版 playbook，验证在固定演示工程中清页回放可重复成功。
3. 植入埋雷版；先用现有 `sch check`、`bridge-check`、`pcb check` 逐雷跑一遍，记录查出与漏报。
4. 漏报项补成机械检查规则（带负对照），再接入 EdaDesk 的审图与演示入口。

每一步结论以保存、重载后的新回读为准；未现场复现的步骤保持 not-run。
