## 修复与运行说明

`pcb.component.delete` 先通过官方 `getAll` 读取当前板器件 ID。请求内任何 ID 不存在或
为空时，整批在写前拒绝；有效 ID 才交给官方 `delete`。离线 typecheck 与 519 个连接器
测试通过，`make skill-check`、`make local-build VERSION=v1.6.0-dev.18` 通过。
Codex 在 Web 扩展管理器卸载 `dev.17`、导入同 UUID 的本地 `dev.18` 包并重新启用
“允许外部交互”；typed `web reload` 成功，耗时约 10 秒。`health` 与测试回包核对运行
版本，完成后用 typed `sch open` 将前台恢复至 P3。
