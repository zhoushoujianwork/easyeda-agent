# 2026-09-24 `dev.15` Web 刷新与基础 CLI 快速复测

## 结论

`easyeda web reload` 首次现场调用在 0.168 秒内失败，未触发页面刷新：连接器的 typed
handler 直接访问 `window.top`，而宿主在该作用域把 `window` 遮蔽为 `undefined`。
这个结果不能算刷新通过，也不能给基础 CLI 门禁放行。

在已保存的测试工程上，开发诊断探针确认浏览器全局作用域中的 `window.top.location.reload()`
能让页面重新加载，并观察到新的 connector window ID。由此形成 `dev.16` 的固定、无用户代码输入
的 typed 修复；`dev.16` 的现场调用尚待同版扩展加载后验证。这里的探针不替代正式命令验收。
