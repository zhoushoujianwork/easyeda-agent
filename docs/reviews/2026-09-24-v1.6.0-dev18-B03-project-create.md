## 归因与能力边界

[官方 createProject 文档](https://prodocs.lceda.cn/cn/api/reference/pro-api.dmt_project.createproject.html)
说明 `teamUuid` 可选，省略时默认个人空间；接口处于 BETA，返回 `undefined` 表示创建失败。
已核对连接器实参顺序与 SDK `@jlceda/pro-api-types@0.4.25` 声明及官方文档一致。

本次仅改变是否传入 `teamUuid`：显式传值立即失败，省略后创建并回查成功。因此，当前
个人空间的可读归属 UUID 不能直接当作可写团队目标使用。该区别也与
[dev.7 的既有现场记录](2026-09-23-v1.6.0-schematic-acceptance.md#dev7-工程创建对账与独立空白起点)
一致。尚未通过真实团队权限/协作模式核查，不把本结论推广成“所有团队创建有故障”。
没有在代码中自动剥离团队参数，避免把用户明确要创建到团队的工程写入个人空间。
