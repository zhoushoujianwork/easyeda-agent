# 无图框原理图 Compose 现场验证（2026-09-29）

## 范围

EasyEDA Pro 4.1.60、连接器 1.8.0、CLI/daemon 1.8.1；在 1.8.1 源码上增加开发态
`paperless:true` Compose/Apply。目标为独立双页电源原理图，两页已放置且绑定库身份，
图框、导线、标记和 NC 均为 0。此记录只证明该现场组合，不代表 PCB 或实板验收。

## 失败与修正

1. 1.8.1 `layout-plan --lib --unbounded` 能生成完整局部候选，发布版 Compose 仍强制要求
   实测图框，无法写入 0 sheet 页。开发态 `paperless:true` 只接受无图框目标，计算内容包络
   作为虚拟几何校验范围。
2. 原 Compose 清页队列把完整图元快照放入约 850KB 命令行参数，运行前失败；改为 typed
   `schematic.page.clear` payload，并为原始属性字符串加入 `literalPayloadKeys` 防止 `${...}`
   被当作队列变量。该修改有单元测试，本次现场空白页未执行清页分支。
3. 连接器的“保留器件清页”动作要求已有图框。空白页经过完整快照证明无导线、标记、
   已赋网或 NC 后，队列跳过清页，保留原生器件实例并逐项移动、接线。已有部分绘图的
   无图框页目前明确拒绝受保护重建。

`go test ./...`、`make skill-check`、`make agent-check` 通过。两页实际写入、保存、
真实重载和完整 Compose 回读完成；这比离线求解或 dry-run 多覆盖了现场持久化。
