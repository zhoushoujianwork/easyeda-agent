## 版本建议与发布条件

按现行[发布规则](../release-workflow.md#version-and-retention-policy)，用户需要更新连接器才能获得
行为变化时递增 minor。本批包含连接器运行时代码修改，因此建议准备 **v1.8.0**。
`1.7.1-dev.11` 是测试包名称，不是正式补丁版已获批准的依据。

目前还不满足现行发布要求：

- 最终同包基础验收未全部通过；当前批次与覆盖范围见 [CLI Status](../cli-STATUS.md#当前状态)。
- 高级设计验收尚未完成；v1.7.0 的 `basic-cli` 范围是当次明确决定，不自动沿用到下一版。
- 中版本需要对应版本的现场通过材料与独立复核，再完成 `release-check` 和资产构建验证。

下一步是确定本次版本和验收范围，完成范围内的修复与验证，再整理正式发布说明、统一版本并检查资产。
不要求为发布关闭所有历史 issue，但不能用已知问题清单代替范围内的通过证据。
本轮基础检查收尾的决定保留；这里记录下次发布需要完成的工作，不自动重启现场全集测试。
