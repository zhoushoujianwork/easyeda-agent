# v1.17.0 软件专项验收基准

## 本版用户范围决定

2026-11-07，用户先要求“1.17版本还需要发布一下，开始发。”；在明确告知现场 EDA 验收未执行、并询问
“按已验证范围发布、现场验收延期”或“先补齐现场验收再发”后，用户回复“直接发吧”。
本版因此采用 schema 3 的 `cli-fixes` 有限范围：已完成的软件自动回归、离线独立复核、构建和安装验证。
真实 EDA 保存、重载、新回读及完整设计 E2E 延期至 follow-up。此决定只绑定 v1.17.0，不能用于后续版本。
报告中的 `pass` 只表示本版明确定义的软件用例通过，不表示电路、制造、硬件或现场设计验收通过。

## 原始需求与起点

完整设计的默认原始需求仍为 `docs/test-case-esp32-blink.md` 第一节。该文件整体 SHA256 为
`21bd4682110228de90ee71a8402680eb7668dad5bb7557d44d368d5ff4cd118c`。
本轮未执行该完整需求流程，没有建立本版本的现场测试板起点，也没有输入预制 BOM、UUID、网表或坐标答案。
浏览器控制宿主不可用；未借用日常工程补签测试，没有把旧版本或 PR 作者的现场记录迁移为本版本通过。

软件测试使用仓库内离线夹具、临时目录和测试自行创建的随机本地端口。
daemon 生命周期验证只终止测试自己创建的子进程；安装验证使用隔离 bin 和 Skill 目录。

## 通过阈值与不豁免项

自动回归不得有失败；已跳过的平台限定测试必须保留跳过事实。所有组件必须使用同一正式版本。
原理图文本单次写入后必须精确 ID 新回读；未知/部分写入不得自动重放或删除。
几何/NC 路径必须保留目标唯一性、预算及写入阶段错误语义，不能削弱几何守卫或 marker 完整指纹。
托管 daemon 必须绑定宿主持有的管道，拒绝占用端口与错误预期身份；旧 OS signal 停止仍非原子。
正式发布仍须独立复核、完整资产校验及公开下载核验。本次范围决定不允许伪造现场回读、放宽设计判据或删除失败记录。

安装脚本的候选测试以精确 URL 映射的本地 curl 替身供给字节；v1.16.0 基线资产来自官方 GitHub 并校验。
该候选测试只能证明安装与替换行为，不能声称尚未发布版本的真实网络下载已通过。
