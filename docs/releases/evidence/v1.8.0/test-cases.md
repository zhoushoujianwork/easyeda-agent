| F2 | dry-run 后执行受保护队列；逐页对象和网络对账、layout-lint、strict gate、DRC、保存重载 | journal 完整，0 overlap、0 fatal，严格检查通过；范围外不变，图纸/图签和对象持久化 |
| E1 | 沿实际器件和导线核对 5V 端子/USB 供电、降压、CH340 数据与 UART、BOOT/RESET、点灯路径 | 电源域、引脚与连接符合需求；所选下载控制方式的逻辑成立；静态设计验收不宣称实板烧录或上电验证 |
| L1 | 从已保存的参数源选择一个核心及其专属外围，声明合法整体移动，重算后 typed 执行并保存重载 | 核心/外围共同跟随，连接和约束保持；未声明对象的身份、属性、网络及几何不变 |
| L2 | 若新鲜回读发现真实局部错误，按参数源修正并对账；没有真实前提时记录依据 | 错误消失且没有新增问题；没有适用缺陷才能由独立复核判 not-applicable，不人为造错取得通过 |
| N1 | 在源副本构造过期状态、缺归属、同件数异连接或受阻局部移动，运行保护入口；核对现场前后快照 | 在首次设计写入前明确拒绝；完整对象及语义哈希不变；未知状态不当作已拒绝且无副作用 |
| R1 | 对相同输入/参数/版本重复计算；在专用测试对象的一次局部批次受控中断，fresh 回读后重算恢复 | 计算可重现；实际已写入部分可逐项解释；不盲重放，恢复及精确清理经保存重载证明 |
| E2E | 从唯一客户需求完整执行 S0–S6 与 P0–P10：原理图、四层 PCB、规则、布局、用户确认、布线、铜、DRC、最终保存重载与导出 | 需求全部落实：网络连通、四层电源树、丝印极性、天线 keepout、四角孔、0 overlap/0 fatal 与持久化；独立复核及成本记录齐备 |

每项记录版本、实际命令、UTC、退出码、参数与输入哈希、目标 UUID、原始回包、fresh 对象和差分。
