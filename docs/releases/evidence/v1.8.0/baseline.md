## 通过标准

先按 [B00–B10](../../../cli-live-test-detail.md)完成同包基础门禁，再运行
[A00–A06](../../../cli-advanced-test-detail.md)与本目录全部必测用例。
客户需求逐条映射、完整物理脚与网络/NC 对账、0 overlap、0 fatal、网络连通、四层电源树、
丝印极性、天线禁布区、四角 M3 固定及最终持久化均需真实证据。
局部修改须证明核心与专属外围整体跟随，范围外对象不变；拒绝和中断恢复另行验证。

所有写入必须来自参数化输入并经 typed CLI。保存、真实重载、新鲜回读和独立复核不可由截图替代。
依赖能力失败时停止对应下游，保存输入和错误，修复并重新验证；不得更换参数或降低标准补签原失败。
