# v1.7.0 发布准备

本版交付基础 CLI 的 Web 重载、项目查找、写入回读与错误拒绝修复，并为三个已知问题增加操作提示。

- #256、#257、#258 继续跟踪；警告不会把失败变成功，部分写入或显式验证失败仍非零退出。

## 升级方式

发布后运行 `easyeda update` 更新 CLI 与 Skill；侧载连接器在扩展插件中卸载旧项，再导入
本版 `.eext`，启用允许外部交互。先保存已打开文档，加载新插件后以 `easyeda health`
确认实际版本与目标工程/页面。连接器市场版本单独维护，不将 GitHub 发布视为市场更新。
