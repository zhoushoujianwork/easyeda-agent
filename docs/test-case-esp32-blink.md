# 固定收尾用例 — ESP32-S3 最小点灯板

2026-09-27 用户选择恢复旧最小点灯用例，作为日常端到端与测试收尾的默认板子。
沿用旧用例的板外稳压 3.3V、模组和点灯范围，核心约 8 件；实际供电、下载接点按设计补齐，
不把“恰好 8 件”作为通过条件。原四层开发板保留为扩展回归。

执行 Agent **只接收第一节客户原始需求**；自行选型、读取真实引脚并生成连接与布局。
执行步骤和证据要求见[详细稿](test-case-esp32-blink-detail.md)，通用判据见[端到端验收](e2e-automation-acceptance.md)。

## 一、客户原始需求

做一块 ESP32-S3-WROOM-1 模组的最小点灯板：

- 板外提供已稳压的 3.3V，板上提供清楚标注的 3V3/GND 接点。
- 保留正常启动、复位所需的基本电路和电源去耦，预留板外下载所需接点。
- 一颗普通 GPIO 控制的 LED，带合适的限流电阻，并标清 LED 正负极。
- 一页原理图、两层 PCB；板框按实际器件安排紧凑确定。
- 保留模组天线所需的禁铜空间；供电、启动、下载和点灯连接正确，符合电气与间距规则。
- 完成原理图、PCB 布局和布线，提供可读的位号、必要丝印，并保存工程。

## 二、范围与收尾

本用例不加入板载 USB/CH340、5V 降压、BOOT/RESET 按键、四角 M3 孔和四层电源树。
下载器及点灯固件由板外提供，软件设计回归不宣称实板已经烧录或上电点亮。

完成只核对四项：需求与连接正确、无重叠/越界、DRC 无错误且全部必接网络连通、保存重载后数据一致。
布局仍按通用规则生成整板预览、完成两轮自检并交用户确认；不为收尾扩展成另一块开发板。
本次仅修改用例文档，新两层完整用例状态为 **not-run**；旧用例及 v1.8.0 结果保持原判。

扩展需求另选 [ESP32 四层开发板](../esp32MiniRequire.md)或[芯片级 N8R8](test-case-esp32-chip-n8r8.md)，
只在任务明确要求或修改影响对应能力时执行。
