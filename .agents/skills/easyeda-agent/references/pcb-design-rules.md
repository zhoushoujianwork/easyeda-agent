## 1 线宽与间距

### 1.1 JLC 工艺极限（不要拿极限当默认）

| 铜厚 | 最小线宽 | 最小间距 |
|------|---------|---------|
| 1oz (35μm) | 0.10mm (4mil) | 0.10mm (4mil) |
| 2oz | 0.16mm | 0.16mm |
| 2.5oz | 0.20mm | 0.20mm |
| 3.5oz | 0.25mm | 0.25mm |
| 4.5oz | 0.30mm | 0.30mm |

线宽公差 **±20%**，设计时留余量。

`pcb check` 必须保留板载 Safe Spacing 的对象对维度：Track↔Track、Track↔Pad/Via
可能不是同一个值（嘉立创 EDA 双层板实测默认分别为 4mil、6mil）。不得取两者最大值后
统一套用，否则会把符合原生 DRC 的 Track↔Track 间距误报为错误；最终仍以同一板载规则下的
原生 `pcb drc` 为裁决。

### 1.2 推荐设计值（easyeda-agent net-class 默认）

| 网络角色 | 推荐线宽 | 说明 |
|---------|---------|------|
| 信号（signal） | 0.15mm (≈6mil) | 普通数字信号；实现中取板载 live 规则默认值（不做公制圆整——用户自己的设定只报告、不改写） |
| 分支电源（branch） | 0.25mm (≈9.84mil) | 器件到去耦电容段 |
| 主干电源（trunk） | 0.4mm (≈15.75mil) | 电源轨主干 |
| 大电流（high-current） | 0.5mm (≈19.69mil) | >500mA 的走线 |
| GND | 同 high-current 0.5mm | 若必须走线；首选铺铜/平面替代（power-not-poured 门禁） |

> 线宽公制圆整原则：用 **0.05mm 步进**（0.15/0.2/0.25/0.3/0.4/0.5…），不用 mil 碎值如 0.127mm 或 10mil=0.254mm。`pcb net-classes` 阶梯的电源各档即按本表落地（`pcb_netclass.go`），旧 10/15/20mil 碎值阶梯已废弃；width-under-spec 有 1mil 容差，按旧 10/15/20mil 布的存量板不会被追溯 WARN。

### 1.3 电流承载估算

| 线宽 (1oz) | 安全电流（外层） | 安全电流（内层） |
|-----------|--------------|--------------|
| 0.15mm | ~0.5A | ~0.3A |
| 0.25mm | ~0.9A | ~0.5A |
| 0.5mm | ~1.5A | ~0.8A |
| 1.0mm | ~2.5A | ~1.5A |
| 2.0mm | ~4.0A | ~2.5A |

### 1.4 3W 规则（线间串扰防护，定义）

来源《通用布局布线规范》。本手册多处（§4.4 等长蛇形、§6.2 连接器地铜皮间距）引用"3W/4W"
作为参数，本节补上规则**本身**的定义：当两条走线的**中心距不小于 3 倍线宽**时，可保持约
70% 的线间电场不互相干扰，称为 3W 规则；间距不足会导致串扰增大。设计前还需考虑铜厚对
最小线距的影响：1oz 铜厚线距尽量保持 ≥4mil，2oz 铜厚线距尽量保持 ≥6mil（advisory，可
按具体加工厂能力做区域规则管控，参见 §1.1 JLC 工艺极限表的间距列）。相邻层信号应避免长
距离平行走线，走线方向尽量成正交结构（呼应 §4.2 相邻层正交布线），减少不必要的层间串扰。

## 2 过孔设计

### 2.1 JLC 工艺极限

| 参数 | 最小值 | 推荐值 |
|------|-------|-------|
| 过孔孔径 | 0.15mm | 0.3mm |
| 过孔盘径 | 0.25mm | 0.5mm |
| 焊环宽度 | 0.20mm | 0.25mm |
| 孔位公差 | ±0.05mm | — |
| 孔径公差 | +0.13/-0.08mm | — |

### 2.2 按用途分类

| 类型 | 孔径 | 盘径 | 用途 |
|------|-----|-----|------|
| 信号过孔 | 0.3mm | 0.5mm | 普通信号换层 |
| 电源过孔 | 0.4mm | 0.7mm | 电源网络 |
| 地缝合孔 | 0.3mm | 0.5mm | GND 平面连通，间距 ≤2mm |
| 散热过孔 | 0.3mm | 0.5mm | 热焊盘下阵列，间距 1mm |
| 安装孔 | 3.2mm | 无铜（or 6mm） | M3 螺丝，边缘无铜区≥1mm |

### 2.3 过孔使用原则

- **高速信号换层必须就近打地孔**（回流路径连续）
- 差分对换层：两个信号孔 + 两个地孔紧邻
- **禁止过孔打在焊盘上**（via-on-pad），除非设计为 filled via
- BGA 扇出：优先 dog-bone 布局，实在不够空间才考虑 via-in-pad（需填孔盖铜工艺）
- **过孔种类宜控制在 ≤3 种**（advisory，来源《通用布局布线规范》）：常见组合
  8/16mil、10/22mil、12/24mil（孔径/盘径）。种类越少，钻孔换刀次数越少，焊接与
  AOI 检测也越简单；本条不改变 §2.2 各类型的推荐孔径/盘径本身，只是提醒同一块板上
  别混用太多规格。
- **过孔扇出间距**（advisory，来源同上）：两个过孔中心间距建议 ≥1mm（39.37mil），保证过孔
  之间能容纳一根信号走线，避免过孔破坏地/电源铜皮完整性。IC 扇出优先选择外侧，多排时左右
  两排过孔宜保持同一水平线，便于内层布线。
- **BGA 电源/地过孔合孔限制**（advisory，来源同上）：BGA 扇出为方便滤波电容摆放可将电源和
  地过孔合孔，但最多允许 2 个管脚共用 1 个过孔，不允许多管脚共用；应尽量避免合孔处理以保障
  电源和地的载流能力。

### 2.4 BGA 扇出几何（advisory）

来源《通用布局布线规范》，补充 §2.3 dog-bone 扇出的具体几何参数（仓库当前无 typed BGA
扇出生成器，供人工/未来实现参考）：

- 扇出过孔宜打在 2 个焊盘对角线中心并向四周扇出，中间十字通道禁止打过孔，以保证该通道的
  电源/地载流能力。
- 最外圈 Ball 可同层用 4mil 线宽直接扇出；第二圈从两个 Ball 正中间以 4mil 线宽扇出；第三圈
  起通常需要换层，换层过孔建议间隔 2–4 排留空一排，给地/电源平面留出足够铺铜通道；也可将
  前两排过孔适当向外拉出一段距离，并与 BGA 中间的过孔对齐，方便内层出线。
- 每层可布线数量随 BGA 间距估算：≥1mm 间距的通道可布 2 根信号线，<1mm 间距通道只能布
  1 根，0.4mm 间距一般只能做 HDI 设计。

## 3 布局原则

### 3.1 优先级顺序（easyeda-agent place-constrained 分档）

```
T1 安装孔 → T2 板边接口(USB/电源/天线) → T3 主芯片 → T4 卫星/配套器件
```

1. **安装孔先放**，确定板框约束
2. **边缘接口次之**：USB/Type-C/电源连接器/天线突出板边或靠边，方向朝外
   （「哪些口该占外沿、聚哪条边、开口朝哪、插头会不会打架」的完整判据见 **§3.5**）
3. **主芯片居中偏上**，留出下方走线空间
4. **去耦电容紧贴 IC 电源引脚**，≤2mm

### 3.2 热设计

- 发热器件（LDO、功率 MOS、大电流 IC）靠板边或有散热孔阵列
- 热焊盘下打散热过孔阵列（0.3mm 孔径，间距 1mm）
- 高温器件与电解电容保持 ≥5mm 间距

### 3.3 模拟 / 数字分区

- 模拟地与数字地**单点汇合**（星形接地）
- ADC/DAC 器件紧靠模拟区，远离时钟/开关电源
- 晶振就近芯片，底部禁止走信号线
- **模拟/数字铺铜分割宽度**（advisory，来源《通用布局布线规范》）：模拟信号与数字信号分开
  铺铜时，分割间隙宽度至少 20mil；模拟和射频部分按模块化设计要求排布成"一"字型或"L"型，
  与数字区不交叉。这是**铜皮分割间隙的数值**，与 `pcb-layout-conventions.md` §4.3 的分区
  间距（元件级 100/200mil）是两个不同维度，二者都满足才算合规。
- 高频信号与低频信号完全分开，间隔距离至少保持 3mm 以上，不能交叉布局（advisory，来源同上）。

### 3.4 元件间距

| 场景 | 最小间距 |
|------|---------|
| SMD 与 SMD | 0.2mm |
| SMD 与通孔 | 0.5mm |
| 器件与板边 | 0.5mm（推荐 1mm） |
| 器件与 V-Cut 线 | 1.5mm |
| 天线区域（RF） | 净空区无铜无器件 |
| 相邻对外连接器（中心距） | ≥ 两者**插头护套包络宽**的均值 —— 判据与查表见 **§3.5.3**（本表其余各行量的是**板上的铜与本体**，插头是板上不存在的三维实体，不在此列） |
| 压接式连接器（弯式，advisory，来源《通用布局布线规范》） | 同面周边 3mm 内不得布局任何高于 3mm 的器件，1.5mm 内不得布局任何焊接件；连接器背面、距压接针脚 2.5mm 范围内不得布局任何元器件 |
| 压接式连接器（直式，advisory，来源同上） | 同面周边 1mm 内不得布局任何元器件；背面需安装护套时周边 1mm 禁布，无护套时背面距压接针脚 2.5mm 内禁布 |
| 常规后焊接插件（同层） | 与接插件间距 ≥1.5mm；背面布局器件时 ≥3mm；插拔连接器/板边连接器周围 3mm 内尽量不布 SMD 器件，防止插拔应力损伤（advisory，来源同上） |
| BGA/QFP 同面器件间距 | ≥5mm；空间拥挤时可放宽到 ≥3mm（advisory，来源同上，交叉引用 §8.2 高/大件吸嘴阴影间距） |
| BGA 双面布局：背面对应正面投影 | 背面若已布局 BGA，正面对应该 BGA 周围 8mm 投影范围内不能再放置 BGA（双面 BGA 重叠限制，不是"大功率散热"通用间距；advisory，来源同上） |
| 双面布局器件层选（无特殊要求时） | 大器件/芯片统一放 TOP 层；背面只放 0805/0603/0402 等小尺寸电阻电容（advisory，来源同上） |

### 3.5 对外接口与板沿

> 本节是 `[规范 §3.5]` 回指的正本；`pcb layout-score` 的 **edge-io（对外接口与板沿）** 维
> 与 #168 两条连接器规则（`internal-on-edge` / `connector-plug-clearance`）全部指向这里。

#### 3.5.1 板外沿是稀缺资源

板框周边一圈（**外沿带，默认 300mil ≈ 7.6mm**）是整块板上**唯一**能让线缆离开外壳的地方，
它的长度由板框尺寸固定、不能靠加层数或缩封装换来。所以外沿的分配是一个**排他决策**：

- **对外口（user-facing）**必须占外沿，且**开口朝板外** —— 外壳要在对应位置开孔，
  开口朝板内的座子只能让线缆先绕进箱内再折出来。
- **对外口应聚在同一条边**。散在四条边 = 外壳开四面孔 + 线束在箱内绕一圈，
  装配成本直接翻倍。板子仍然能用，所以这是 WARN 级而不是硬错。
- **内部件（internal）不该占外沿**。备份电池座、板间排针这类只在箱内连线的连接器
  占了外沿，等于把可达边让给了不出线的件，而它的辫线还得从板边绕回箱内。
- **edge-agnostic（any）**：RF 天线座 / 无线模组必须在**某**条边（天线净空要伸出板外），
  但哪条都行 —— 判「聚一条边」时要把它们排除，否则天线单独占一条边就会被当成散乱。

#### 3.5.2 三档 edge role 与语义来源的置信度

「这个连接器对内还是对外」是**设计意图，不是几何属性**：同一个 PH2.0-3P 座，接箱内电芯
是 internal，接箱外传感器就是 user-facing。铜箔再精确也推不出来。因此结论必须**带来源**：

| 来源 | 怎么写 | 置信度 | 能定出哪几档 | internal-on-edge 报告级别 |
|------|--------|--------|-------------|------------------------|
| **spec 显式** | S0 spec `interfaces[].facing` / `internal:true`（配 `ref` 钉到位号） | 板级决定，最高 | 三档全部 | **WARN** |
| **块库 hint** | 块 `placement.<ROLE>.edge` = `user-facing` / `any` | 器件类别的通用知识 | 只有 user-facing / any（**块从不声明 internal**——那是板级决定） | 不触发（它只把件判成对外） |
| **启发式** | 线对板封装（JST PH/XH/ZH/SH、Molex…）**且**一个对外语义网都没有 → 推定 internal | 类别经验，会错 | 三档全部 | **INFO**（不阻塞） |

优先级 **spec 显式 > 块库 hint > 启发式**：板级决定比类别经验更具体。启发式只报 INFO，
是因为它会把「接箱外传感器的 XH 座」误判成内部件 —— 这种误报不该阻塞任何人。
判不出来时（facing 为空）一律按**对外**处理：位号 `J*` 默认是对外口，这是 EDA 通行约定，
也是保守的那一侧（宁可漏报，别乱扣一个备份电池座的分）。

> **推论：想让 internal 判定升到 WARN 档，只有一条路 —— 在 S0 spec 里写 `ref` + `internal:true`。**
> 块库帮不上忙（同一个 PH2.0 座在不同板上朝向不同），启发式又故意压在 INFO。
> 反过来，被启发式误判的件（接箱外传感器的 XH 座）也是写一条 `facing:"user-facing"` 就消除。

#### 3.5.3 插头护套包络 ≠ 母座本体宽

PCB 上看得见的只有**母座的 footprint / 铜箔**，而装配时真正打架的是**插头护套 + 线缆 overmold**
——它常比母座本体宽好几毫米：

| 器件 | 母座本体宽 | 插头护套包络宽 |
|------|-----------|--------------|
| USB Type-C | ≈8.94mm | **≈13mm**（3A/5A 粗线常见 12–14mm） |
| USB Type-A | ≈13.2mm | **≈18mm** |
| DC-005 电源座 | ≈9mm | **≈12mm** |

**判据**：两个**对外**连接器的中心距 `d` 必须满足

```
d ≥ (envelope_A + envelope_B) / 2
```

`envelope` = 插拔这个口时侧向占用的宽度，取**插头护套宽与母座本体宽的较大者**
（这样定义保证包络永远不会比 footprint 还窄）。三条收窄，都是为了少报假警：
① 只比对外口（internal 件归 §3.5.1 治理，不重复扣）；② 只比**同一装配面**（异面插头被板厚
在 Z 向错开）；③ 有板框时只比**同一条板边**（分处对边的两个口朝相反方向插，中心距再近也插得进）。

**包络宽从哪来（三级）**：
1. **S0 spec 人工覆盖** —— `interfaces[].plugWidthMm`（手上有真插头时最准）；
2. **块库查找表** `internal/blocks/data/_plug_envelope.json` —— 13 条，每条带
   `confidence`（`datasheet` / `measured` / `estimated`）与 `reason` 出处。排式连接器
   （XH/PH/KF301/排针）按 `pitch_mm × (pins−1) + plug_margin_mm` 随脚数算；
3. **bbox 兜底** —— 沿板边方向的渲染 bbox 跨度 **+2mm**，报文里一律标 `plug-width=fallback`，
   让读的人知道这条是估出来的。

> ⚠️ **既有工具一条都抓不到这类问题**：`layout-lint` 的 overlap 与 `pcb check` 的 clearance
> 只看铜箔与渲染 bbox；插头护套是板上**根本不存在**的三维实体，几何里没有它，再精确的
> bbox 判定也永远看不见。实测证据：box-v2 rev-a 底边三口中心距 12–13mm，按母座 ~9mm 判**全过**，
> 按插头护套判才暴露。

#### 3.5.4 本节各阈值的状态

`300mil` 外沿带、`+2mm` 兜底余量、表里标 `estimated` 的各条包络宽**都是待校准初值**。
校准闭环：`easyeda pcb dump` 把一块公认的好板抓成离线 fixture → `pcb layout-score --from <file>` 重放
→ **好板在 edge-io 维掉分 = 判据或数值错了，回来改本节（以及代码里对应的常量），不是去改板子**。
量到真插头尺寸时，往 `internal/blocks/data/_plug_envelope.json` 补一条并把 `confidence` 升到 `measured`。

## 4 走线规范

### 4.1 转角

- **禁止 90° 直角走线**（阻抗突变 + 制造腐蚀坑）
- 推荐 **45° 折线** 或 **圆弧**（easyeda-agent `pcb beautify` 自动圆化）
- 圆弧半径 ≥ 线宽的 3 倍
- 走线拐角离焊盘位置宜 ≥6mil，从焊盘长方向出线，避免从宽方向或焊盘四角出线（advisory，
  来源《通用布局布线规范》）。
- **相邻同网络焊盘禁止直接相连**（advisory，来源同上）：两个相邻焊盘属于同一网络时，不能
  直接一条线连接短接，需要先各自连接出焊盘之后再进行连接——直接相连容易在手工焊接时造成
  连锡短路的外观问题（即使原理上同网不算电气错误）。
- IC 管脚出线的线宽宜 ≤ 焊盘宽度；部分信号因载流等要求需要更宽走线时，可先保持与管脚宽度
  一致，出焊盘后 6–10mil 左右再加粗（advisory，来源同上）。
- **走线长度的统计口径**：计算一条走线的总长度时应包含过孔与封装焊盘本身的长度，不能只算
  两个焊盘/过孔之间的裸线段——等长比对（§4.4）按这个口径才准确（advisory，来源同上）。
- 布线应避免直角或锐角转角，转角处线宽会发生变化导致阻抗突变、引发信号反射；优选
  135° 角出线方式，任意角度出线在制版环节容易出现工艺问题（advisory，来源同上，是对本节
  已有"禁止 90° 直角走线"规则的**角度范围补充**——不仅 90° 禁止，任意非 135°/45°/圆弧的
  随意角度都不推荐）。
- **同一网络的布线宽度应保持一致**：线宽突变会造成特性阻抗不均匀，高速传输时容易产生反射；
  在接插件引出线、BGA 封装引出线等因间距过小确实无法避免线宽变化的场景，应尽量缩短线宽
  不一致段的有效长度（advisory，来源同上）。

### 4.2 走线层规则（4层板默认）

| 层 | 用途 | 走线方向 |
|----|------|---------|
| Top | 水平为主 | 横向 |
| Inner1 (GND PLANE) | 地平面，不走信号 | — |
| Inner2 (PWR PLANE) | 电源平面，不走信号 | — |
| Bottom | 垂直为主 | 纵向 |

相邻层走线方向正交，减少串扰。

- **电源层信号内缩**（advisory，来源《通用布局布线规范》）：电源层的信号铜皮应比同层
  GND 铜皮内缩 10mil 以上距离；电源与电源之间的铜皮间距也应保持 10mil 以上，部分间距较小
  的 IC（如 BGA）下方可适当调整到 ≥6mil（可用区域规则管控）。这是**电源层内部铜皮之间**
  的净空，与 §5.1「铜皮到板边间距」是两个不同的边界对象。

### 4.3 回流路径

- 每条高速信号线下方需有完整的参考平面
- 换层时就近打地孔，保证回流路径连续
- **禁止在地平面上走信号线切割地平面**
- 换层且换层前后参考层均为地平面时，需在信号过孔旁放一个伴随过孔以保证回流路径连续；差分
  信号的信号过孔与回流过孔应对称放置，单端信号建议在信号过孔旁放一个回流过孔以降低过孔间
  串扰（advisory，来源《通用布局布线规范》）。
- **避免走线在不同层间形成自环**：多层板设计容易出现此类问题，自环会引起额外的辐射干扰
  （advisory，来源同上）。
- **不建议在高速信号上放置测试点**（advisory，来源同上）：与 `pcb-layout-conventions.md`
  §8.7 的正向要求（关键 net/电源轨应有探针点覆盖）互补而不矛盾——普通关键 net 需要探针覆盖，
  但高速信号本身尽量不额外引出测试点分支，避免测试点引线造成阻抗突变/寄生。
- 走线残桩（STUB）应尽量消除，建议残桩长度为零；尤其过孔残桩长度超过 12mil 时，建议通过
  仿真评估其对信号完整性的影响（advisory，来源同上）。仓库当前无自动 STUB 检测工具，人工
  布线/审图时参考。
- 表贴器件（电容、ESD、共模抑制电感、连接器等）焊盘正下方，可按焊盘大小在参考层挖去一小块
  铜以降低阻抗突变的影响；这是一条降低表贴焊盘导致阻抗降低效应的可选技巧（advisory，来源
  同上），与 `pcb-layout-conventions.md` §7.5 参考平面连续性的"不得跨分割"要求不冲突
  （挖空区域小于焊盘尺寸，不构成真正的分割）。
- 高速信号应避免跨越参考平面的分割区域，建议高速信号距参考平面的边沿保持 ≥40mil（advisory，
  来源同上）。这是**参考平面内部分割边沿**的净空，与 `pcb-layout-conventions.md` §8.5
  「板边净空」（高速件 100–125mil，量的是器件/走线到**物理板框**的距离）是两个不同的边界——
  参考平面分割边沿可能出现在板内部任意位置，不一定挨着物理板边。
- 信号线与其回路构成的环路面积应尽量小：环路面积越小，对外辐射越小，接收外界干扰也越小
  （advisory，来源同上，是对本节"完整参考平面"要求的效果说明，不是独立新增门禁）。
- 走线经过定位孔（非安装孔，指工艺定位/校准用途的孔）附近时，若走线在表层，应与定位孔保持
  ≥1mm 距离，防止安装时出现短路或安装应力造成的线路撕裂断路（advisory，来源同上）。

### 4.4 等长规则

| 场景 | 等长要求 |
|------|---------|
| DDR 数据总线 | 组内等长 ±25mil |
| USB DP/DM 差分对 | 对内等长 ±5mil |
| 以太网差分对 | 对内等长 ±5mil |
| 时钟分配 | 全局等长 ±50mil |

**等长蛇形走线几何参数**（advisory，来源《通用布局布线规范》，补充上表的等长*目标*误差，
本条给的是蛇形走线本身的*形状*参数——上表回答"允许差多少"，本条回答"用什么几何绕出这个
差值"）：

- 蛇形走线间距优先 4W（线宽的 4 倍），空间受限时可调整到 3W；等长高度（蛇形凸起的幅度）
  控制在 40–150mil 为宜，不宜过高。
- 转角长度不小于线宽的 1.5 倍，一般控制在 6–10mil；例如线宽 4mil 时转角控制在 6mil 左右，
  转角不能太小。
- 蛇形走线方向宜保持水平或竖直，避免处理在斜线上；同一设计内多组蛇形走线的高度应尽量接近，
  不要相差太多，便于整体走线美观和空间利用率。
- 处理完等长后应检查参考层情况，不允许跨分割；当参考平面跨越电源层时，建议在两个电源层
  各加一个对地电容以提供完整回流路径。差分对内部的等长应尽量放在不耦合的位置附近处理。

## 5 铺铜规范

### 5.1 铺铜参数

| 参数 | 推荐值 |
|------|-------|
| 铜皮到走线间距（Clearance） | 0.3mm (12mil) |
| 铜皮到板边间距 | 0.5mm |
| 最小铜皮面积 | 1mm² |
| 去孤岛 | 开启（面积阈值 1mm²） |

### 5.2 铺铜策略

- **2层板**：Top 铺 GND，Bottom 铺 GND（或电源），`pcb power-pour` 命令
- **4层板**：Inner1=GND PLANE，Inner2=PWR PLANE，Top/Bottom 信号层局部铺铜补强
- 铺铜网络优先 GND，电源轨用局部 pour（避免异网短路）
- **动态铺铜（pour）优于静态填充（fill）**，防止设计变更后孤岛

### 5.3 铺铜禁忌

- 禁止在天线/RF 模块下方铺铜（各层均需 keepout）
- 禁止铺铜穿越晶振底部
- 差分对之间不铺铜（保持阻抗一致性）

**器件级 keep-out 检查清单**（advisory，来源《蓝桥杯EDA&成图各类问题总结》，交叉引用
`pcb-routing.md` 的 antenna region 示例与 `pcb-layout-conventions.md` §7.7 天线 keep-out）：

- **电感**：本体下方及周边整层禁铜（磁场耦合会在铜皮上产生涡流损耗，也会改变电感值）。
- **晶振**：底部整层禁铜；常见 2 角、4 角两种封装都需要按 courtyard 整体禁铜，不是只避开引脚。
- **继电器**：触点/线圈下方禁铜，避免高压侧与铜皮爬电距离不足。
- **光耦**：隔离侧（primary/secondary）跨界处禁铜，配合 §3 安全间距。
- **天线及天线芯片**（含 ESP32 系列自带 PCB 天线的裸片/模组）：本体及馈线周边各层禁铜，
  详见 `pcb-layout-conventions.md` §7.7 与 §7.10。
- **以太网接口**：磁隔离变压器/RJ45 下方禁铜，避免与隔离侧铜皮产生耦合。
- **碎铜清理**：铺铜后清理面积小于阈值（见 §5.1 最小铜皮面积）的孤立铜岛，防止工艺缺陷
  与 EMI 隐患，`pcb pour.create` 的去孤岛开关即对应此项。

## 6 电源与地

### 6.1 电源树设计

```
外部输入 → 防反接(P-MOS/肖特基) → 主 LDO/DC-DC → 各子系统
```

- 每个电源域加 **去耦电容**：大电容（10–100μF）在入口，小电容（100nF）紧贴每个 IC
- 去耦电容优先级：先放 100nF 贴片电容，再放 10μF

### 6.2 地设计策略

| 板型 | 地策略 |
|------|-------|
| 简单 2层单域 | 单 GND 铺铜平面 |
| 2层多域（模拟+数字） | 分区铺铜 + 单点桥接 |
| 4层板 | Inner1 = 完整 GND PLANE，单点汇合 |

- **禁止地分割成孤岛**（检查 DRC No-Connection）
- 地缝合过孔间距 ≤ 最高频率波长的 1/20（USB/高速信号旁 ≤2mm）
- **电源平面分割规则**（advisory，来源《通用布局布线规范》）：一个电源平面内处理的电源信号
  数量不宜超过 5 个，最好控制在 3 个以内，以保证载流能力并规避相邻层信号跨分割的风险。
  分割形状要尽量保持规则，**不允许出现细长条及哑铃形分割**（两头大中间小），并按电源铜皮
  最窄处的宽度计算实际载流能力——最窄处才是整条铜皮的载流瓶颈。本条是 §7.9（`pcb-layout-
  conventions.md`）"≥2 地域→全 SIGNAL 分区 pour"判据下**分区形状本身**的补充细则，不改变
  判据本身。
- 连接器的地铜皮距离信号 PAD 至少要大于等于 3 倍走线线宽，即遵循与 §1.4 3W 规则同源的间距
  逻辑（advisory，来源同上）。
- 在 BGA 区域，平面断开处要用走线连接，或做削盘处理，避免破坏平面完整性（advisory，来源
  同上）。
- PCB 需要包地处理时，推荐地过孔间隔（L）与包地线到信号线间距（D）满足 D ≥ 4×W（W 为
  信号线宽）；部分重要高速单端信号（时钟、复位等）建议包地，包地线每隔 500mil 至少打一个
  地孔（advisory，来源《通用布局布线规范》）。对于单对或多对高速信号（如 ADC 采集、高速
  差分对），在满足 3W 规则及空间足够的情况下也可对整条线路做包地处理，两条地过孔的间距保持
  在 50–150mil 左右（advisory，来源《蓝桥杯EDA&成图各类问题总结》）——与前一条 500mil 间隔
  不冲突：前者是**关键单端信号**（时钟/复位类）沿线定期加固的地孔密度，后者是**整条线路
  包地屏蔽线本身**上地孔的常规间距，取值场景不同，都可按实际信号等级选用。
- 对于会产生干扰或者敏感的信号（如射频信号），须规划屏蔽罩：屏蔽罩宽度常规为 40mil（一般
  保持 ≥30mil，具体可与生产厂家确认），屏蔽罩上尽量多打 GND 过孔以增加焊接效果（advisory，
  来源《通用布局布线规范》）。

### 6.3 电源线宽快速查表

| 电流 | 推荐线宽（1oz，外层） |
|------|-------------------|
| <100mA | 0.15mm |
| 100–500mA | 0.25mm |
| 500mA–1A | 0.5mm |
| 1–2A | 1.0mm |
| 2–5A | 2.0mm |
| >5A | 铺铜平面或多并联过孔 |

## 7 差分对与高速信号

### 7.1 差分对规则

- 线宽/间距决定阻抗：USB 2.0 差分对通常 **0.1mm 线宽 / 0.1mm 间距** = 90Ω（具体值需阻抗计算）
- 对内等长 ±5mil，全程紧耦合（不分离）
- 过孔成对使用，旁边打地孔
- 禁止在差分对中间放置过孔或走其他信号
- 差分信号换层时，换层过孔附近必须加 GND 过孔以保证回流路径短；差分信号两个过孔中间，
  所有层保持净空，禁止其它信号从中间穿过（advisory，来源《通用布局布线规范》，与前一条
  "禁止在差分对中间走其他信号"是同一意图在**过孔换层场景**下的具体化）。
- 差分信号出线方式应保持耦合与对称，尽可能减少不耦合长度（advisory，来源同上）。

### 7.2 USB 走线规范

- DP/DM 差分对等长，靠近处理，远离时钟
- ESD 器件就近连接，走线尽量短（≤5mm）
- USB 5V 走线独立，不与差分对交叉
- Type-C：A6/B6 + A7/B7 tie 双取向（见 `concepts.md` §usb-c-topology）

### 7.3 SPI / I2C 时钟规范

- SPI CLK 就近终端电阻（33Ω 串联）
- I2C 上拉电阻靠近主控端
- 长走线（>5cm）加终端匹配

### 7.4 存储器/高速外围补充惯例（advisory）

来源《通用布局布线规范》：

- 设计中包含多片 DDR 或其他存储器芯片时，须先向客户/数据手册确认布线拓扑结构（如 T 型、
  星形、菊花链），确认是否有官方参考设计文档，不能凭经验假定拓扑。
- 金手指区域需要开整窗处理；多层设计时，金手指下方所有层的铜均应做挖空处理，挖空铜皮距离
  板框一般 ≥3mm。
- 耦合电容尽量靠近连接器放置；串接电阻应靠近发送端器件放置，端接电阻靠近接收末端放置——
  例如 eMMC 时钟信号上的串接电阻推荐放在靠近 CPU 侧（400mil 以内）。
- 建议在 IC（如 eMMC 颗粒、FLASH 颗粒等）的地焊盘各打 1 个地过孔，有效缩短回流路径；ESD
  器件的每个地焊盘也建议打一个地过孔，且尽量靠近焊盘；高速连接器的每个地焊盘至少打一个
  地过孔。
- 避免在时钟器件（晶体、晶振、时钟发生器、时钟分发器）、开关电源、磁性器件、插件过孔等
  周边布线——这是**走线级**的净空要求，与 `pcb-layout-conventions.md` §7.1 晶振**摆位级**
  的 200mil 守护环是两个不同维度：守护环管"谁能摆在旁边"，本条管"谁的走线能经过附近"，
  两者都满足才算合规。

## 8 过孔用法进阶

### 8.1 背钻（Backdrill）

JLC 支持背钻，用于高速背板减少 stub，普通项目不需要。

### 8.2 盲埋孔

JLC 支持，需额外报价，普通 4 层项目用通孔足够。

### 8.3 过孔阵列（电源/散热）

- 电源过孔：每 500mA 打一个 0.3mm 过孔
- 散热过孔阵列：0.3mm 孔径，1mm 间距，规则排列在热焊盘下

### 8.4 板边 GND 过孔环与铜平衡（advisory）

来源《通用布局布线规范》：

- 板边应沿着板框内缩的位置打一圈 GND 过孔，过孔与过孔的距离建议在 50–200mil 左右——这是
  §7 天线/信号 keep-out 之外，板框本身的一圈地缝合环，用于板边屏蔽与回流。
- 多层板设计时避免大面积无铜情况：应避免某一区域内所有层都无铜，否则板上各处铜密度差异
  过大，温度变化时热胀冷缩会导致板子弯曲，尤其是面积较大时更明显。
- PCB 设计完成后须对铜皮做修铜处理，消除尖角，并检查、清除板上的孤铜（严禁孤铜存在）——
  对应 §5.1 的去孤岛铺铜参数，本条是**收尾巡查动作**，与去孤岛开关配合而非重复。
- 大面积铺铜的通孔焊盘（尤其多层板 GND 网络、且器件 >0805 封装的通孔焊盘）一般采用十字
  连接（热隔离焊盘）处理，防止焊接时散热过快导致焊接不良。

## 9 Mark 点设计

### 9.1 必要性

SMT 贴片必须有 Mark 点（Fiducial Mark），用于贴片机视觉对位。

### 9.2 规格

| 参数 | 要求 |
|------|------|
| 形状 | 实心圆形铜箔 |
| 直径 | 1.0mm（推荐） |
| 空旷区（无阻焊） | Mark 点圆心外 1mm 圆形净空 |
| 净空区 | 无铜皮、无丝印 |
| 数量 | 每面 ≥ 3 个（不共线） |
| 位置 | 板角（距边 ≥5mm），三角形布置 |

### 9.3 局部 Mark 点

QFP、BGA 等细间距 IC，焊盘附近需局部 Mark 点（Local Fiducial）：
- 对角 2 个，距 IC 边缘 1–2mm
- 同等规格（1mm 圆 + 1mm 净空）

### 9.4 常见数量配置（advisory）

来源《蓝桥杯EDA&成图各类问题总结》。仓库当前 mount-holes/Mark 点工具只做「≥3 个不共线」
的通用校验（见 §9.2），未提供按下列档位生成的 typed 接口；本节仅供人工摆放时参考，
若后续要机械化需先补 typed 生成器再验证。

| 数量 | 常见布置 | 适用场景 |
|------|---------|---------|
| 4 点 | 板四角 | 标准配置，覆盖绝大多数常规板 |
| 6 点 | 四角 + 两长边中点 | 大板或需要额外基准点提高贴片精度 |
| 8 点 | 沿板周细分等距 | 超大板或高精度贴片场景 |

## 10 工艺边与拼板

### 10.1 工艺边（工艺翻边）

SMT 贴片时传送带夹持需要工艺边：

| 参数 | 要求 |
|------|------|
| 宽度 | **5mm**（JLC SMT 标准） |
| 位置 | 长边两侧（传送方向垂直边） |
| 工具孔 | 2mm 非金属化孔，距边 ≥1.5mm |
| Mark 点 | 3 个（不共线），在工艺边上 |

**传送边选边逻辑与辅助边宽度**（advisory，来源《通用布局布线规范》，是通用 DFM 判据而非
仅比赛物流）：一般长边做传送边；当短边与长边的长度比 >80% 时，短边也可以做传送边（即接近
正方形的板两条边都可以）。若板边 5mm 内没有贴片器件，可以不加传送边以节省板材；一旦布局
无法满足传送边宽度要求（即板边 5mm 内被占用），应采用加辅助边的方法：无需拼板的 PCB
辅助边宽度取 5mm，需要拼板的 PCB 辅助边宽度最小取 8mm。采用邮票孔拼板方式时另需核对
邮票孔参数。

### 10.2 拼板规则

| 分板方式 | 铜皮到切割线 | 适用场景 |
|---------|-----------|---------|
| V-Cut（邮票孔） | ≥0.4mm | 规则矩形板，批量生产 |
| 路由槽 | ≥0.2mm | 异形板，高精度分离 |
| 邮票孔（鼠咬） | — | 不规则形状 |

拼板建议：
- 单板数量：2–6 块/拼板
- 拼板尺寸：150–200mm 为佳（贴片机最优）
- V-Cut 槽角：25°
- 板间距（路由）：≥2mm，推荐 3mm

## 11 丝印规范

### 11.1 JLC 工艺极限

| 参数 | 最小值 | 推荐值 |
|------|-------|-------|
| 线宽 | 0.15mm | 0.2mm |
| 字高 | 1.0mm (40mil) | 1.2mm |
| 字符间距 | 0.15mm | — |

### 11.2 设计原则

- 位号、极性标记、引脚 1 标记**必须清晰可辨**
- 丝印**不能压焊盘**（会影响焊接）
- 极性标记：电解电容标 `+`，二极管标 `A`（阳极）或三角形箭头
- 连接器：每 pin 标功能名（如 `3V3 / GND / TX / RX`）
- 双面贴片：底层丝印从底面看须可读。**程序化判定只覆盖无歧义的两类**——`reverse`（任一层）
  与顶层 `mirror`；底层 `mirror` 的平台语义未确证，`pcb check` 不判（见 `pcb-routing.md`
  底面视觉 QA 一节）
- 靠板边的连接器丝印在板内侧

## 12 叠层设计

### 12.1 2层板

```
Top (Signal + 铺铜GND)
Bottom (Signal + 铺铜GND/PWR)
```

适用：低速，简单电路，成本优先。

### 12.2 4层板（easyeda-agent 默认）

```
Top      — 信号 + 局部铺铜
Inner1   — GND PLANE（完整，不走信号）
Inner2   — PWR PLANE（电源轨或 GND 次选）
Bottom   — 信号 + 局部铺铜
```

- Inner1 紧贴 Top（EMI 屏蔽效果最好）
- Inner2 可分割成多个电源域（GND / 3V3 / 5V 分区）

### 12.3 铜厚选择

| 场景 | 外层铜厚 | 内层铜厚 |
|------|---------|---------|
| 普通信号板 | 1oz | 0.5oz |
| 中等电流（≤3A） | 1oz | 1oz |
| 大电流（>3A） | 2oz | 1oz |

### 12.4 GND 走 PLANE 与走 SIGNAL 的适用场景澄清

两种做法都对，区分点是**地域数**，不是哪个"更先进"：

- **单一 GND 域**：走真内电层 PLANE。本仓 `pcb power-planes`（默认开 `--gnd-plane`）/
  `pcb stackup set --plane` 已有验证过的 API 配方——先在信号层铺 GND，再翻内电层类型，
  最后 `pcb pour-rebuild`（详见 `pcb-layout-conventions.md` §7.7）。
- **≥2 个地域**（需要分区铺铜、后续还要改铺铜边界）：保留 SIGNAL 层手动铺铜，逐层按
  region 划分地域边界、单点桥接。这正是 `pcb-layout-conventions.md` §7.9 地策略判据表
  已覆盖的场景。

《蓝桥杯EDA&成图各类问题总结》建议"不要选内电层，不好改铺铜"是一条保守的通用建议——
默认假设不确定会不会分域时选更容易改的 SIGNAL 层。这与本仓按地域数分档的判据并不矛盾，
只是本仓判据更细：已知只有一个 GND 域时，PLANE 的参考完整性收益大于"不好改"的代价。

## 13 DRC 检查清单

### 13.1 必过（FATAL，0 tolerance）

- [ ] 无短路（Short Circuit）
- [ ] 无断路（Open Net / No-Connection）
- [ ] 线宽 ≥ 0.10mm
- [ ] 间距 ≥ 0.10mm
- [ ] 过孔孔径 ≥ 0.15mm
- [ ] 天线 keepout 区域无铜（各层）
- [ ] 安装孔周边无铜（≥1mm）

### 13.2 必过（ERROR，非零退出）

- [ ] 元件无重叠（Overlap）
- [ ] 网络全连通
- [ ] SMT 板有 Mark 点（≥3，不共线）
- [ ] 丝印不压焊盘

### 13.3 推荐通过（WARN）

- [ ] 线宽按 net-class 规范（power-not-poured / width-under-spec）
- [ ] 电源网络已铺铜（power-not-poured = 0）
- [ ] 无 90° 走线转角
- [ ] 去耦电容紧贴 IC（≤2mm）
- [ ] 差分对等长误差 ≤5mil
